Capture a bug, feature, or improvement and create a structured backlog item.

**Canonical spec:** [.cursor/skills/create-issue/SKILL.md](.cursor/skills/create-issue/SKILL.md) — follow that file for the required fields, board target, and update format.

**Config:** Connection details (board URL, ID, MCP server) are in `Knowledge/workspace-tools.md` under **Backlog**.

**Summary:** Collects title, TL;DR, current vs expected state, relevant files (max 3), type, and priority — then creates the item on the Backlog board with a structured update. Designed to be fast so the user can get back to work.
