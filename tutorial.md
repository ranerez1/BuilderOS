## Tutorial

### What this is
This file is a starting point for documenting how to use BuilderOS.

### Prerequisites
- macOS or Linux
- Git

### Getting started
1. Clone the repo
2. Create your first artifact in `Outputs/`
3. Capture notes in `Learnings/`

### Repo layout
- `Knowledge/`: templates and reference material
- `Learnings/`: notes and experiments
- `Tools/`: helper scripts/tools
- `Outputs/`: generated outputs/artifacts

### Next steps
- Add your first template under `Knowledge/Templates/`
- Add any scripts under `Tools/`
