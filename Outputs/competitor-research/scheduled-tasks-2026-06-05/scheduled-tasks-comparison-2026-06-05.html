Per-competitor notes

todoist

  • Task-view Date scheduler + Quick Add NLP are primary scheduling surfaces
  • Deadline vs planned date is a distinct two-field model (Pro)
  • Duration capped at 24h; no multi-day duration block
  • Today view: Overdue section with Reschedule; red overdue dates
  • Sidebar Today/Upcoming with task count badges
  • Connect calendar promo on Today view

ticktick

  • Today view: Overdue 3 section with Postpone; red overdue dates
  • Smart lists: All (14), Today (3), Next 7 Days (3), Inbox (5)
  • Recurring task icon on task rows
  • Calendar-first scheduling with drag, arrange, batch postpone (docs)
  • Duration supports multi-day All Day spans (docs)
  • Three recurrence semantics in help docs
